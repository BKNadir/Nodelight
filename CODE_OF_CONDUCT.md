# Code of Conduct

Be respectful. Participation in this project (issues, pull requests, discussions) must be free of
harassment, discrimination, personal attacks and trolling, whatever someone's background or experience
level.

- Discuss code and ideas, not people. Disagree politely and give reasons.
- Assume good faith, and help newcomers.
- Do not publish other people's private information.

The maintainer may edit, hide or remove comments, issues and pull requests that break these rules, and
may block repeat offenders. To report a problem, contact the maintainer through the contact address in
the [code signing policy](README.md#code-signing-policy) or through a private GitHub message.
